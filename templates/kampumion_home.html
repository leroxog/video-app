💻 Kampumion

3+ Spieler empfohlen. Eine Person ist im Hackerraum blind, eine taub, eine stumm -- der Rest muss ihr per Sprachchat und einer gehackten KI helfen, den Code zu knacken.

Blind: Bildschirm ist schwarz -- ein Tastendruck zeigt kurz einen Blitz. Tippt am Ende den Code ein.

Taub: hört niemanden über Sprachchat.

Stumm: wird von niemandem über Sprachchat gehört.

Alle sehen den Terminal-Bildschirm und können die KI im Terminal-Panel nach Hinweisen fragen -- nur der/die Blinde darf den Code eintippen.
